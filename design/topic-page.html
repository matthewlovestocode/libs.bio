import { EcoRI, BamHI, RestrictionBatch } from "@biolibs/restriction";
import { bandPosition, gelById } from "@biolibs/gel";

// The calls the tool in the Do view just made, with your sequence in place of `plasmid`.
const fragments = new RestrictionBatch([EcoRI, BamHI]).catalyse(plasmid, { linear: false });
const gel = gelById("1.0");
fragments.map((piece) => bandPosition(piece.length, gel));

A restriction enzyme is a protein that cuts DNA wherever it finds one short pattern of letters. EcoRI looks for GAATTC and cuts between the G and the first A, on both strands, leaving a short single-stranded overhang.

On a gel, the pieces are pulled through a mesh by a current. Short pieces slip through faster, so they travel further. A ladder of known lengths runs beside them, and you read a piece's length by seeing which rungs it sits between.
